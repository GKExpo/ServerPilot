# ServerPilot 1.0.0

Initial public Windows release.

## Downloads

- `ServerPilot-Setup-1.0.0.exe`: Windows installer
- `ServerPilot-Portable-1.0.0.exe`: portable Windows executable

## Highlights

- Multi-server local Minecraft management
- One-click Paper/Fabric/Forge/Vanilla server launch
- Live console and command input
- Playit.gg auto-start and shutdown
- Player tracking from Minecraft logs
- Players dashboard with activity feed and moderation command templates
- Server file manager with Monaco Editor
- Visual properties editor
- Backup and restore system
- CPU, RAM, uptime, process ID, and status monitoring

## Recommended First Setup

1. Install Java 17 or newer.
2. Download Paper from https://papermc.io/downloads/paper
3. Create a server folder and rename the downloaded JAR to `paper.jar`.
4. Download Playit.gg from https://playit.gg/download if you want public access.
5. Install ServerPilot.
6. Add your server folder in ServerPilot.
7. Start the server and accept the Minecraft EULA if prompted.

See the README for the full setup guide.
